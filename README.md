# RISE Contributor License Agreements

This repository contains the Contributor License Agreement (CLA) documents used for contributions to repositories owned or maintained by RISE GmbH.

The purpose of this repository is to provide a transparent, version-controlled source for CLA documents, related governance information, and integration material for automated CLA checks in GitHub pull requests.

## Purpose

RISE requires contributors to accept an applicable Contributor License Agreement before their contributions can be merged into protected repositories.

The CLA process helps ensure that contributions can be legally used, modified, distributed, and maintained by RISE GmbH and the relevant open-source or internal project teams.

This repository is the authoritative source for the current CLA document versions.

## CLA Documents

This repository provides two CLA variants:

| Document | Intended for | File |
|---|---|---|
| Individual CLA | Private individuals contributing in their own name | `rise-individual-cla.pdf` |
| Corporate CLA | Companies, organizations, or contributors acting on behalf of an organization | `rise-corporate-cla.pdf` |
